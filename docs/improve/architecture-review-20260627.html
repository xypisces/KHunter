Problem

BacktestEngine._process_sell() 和 StrategyRunner._execute_sell_operations() 实现了相同的止损/追踪止损/冷却逻辑，但成本模型已经漂移。回测结果和实盘可能不一致。TradingCoreMixin 只抽取了状态初始化，最复杂的卖出循环反而被复制了。

Solution

将卖出逻辑下沉到 TradingCoreMixin，统一成本模型。BacktestEngine 和 StrategyRunner 都通过同一接口调用。回测和实盘共用同一实现，消除漂移。

  • locality: 卖出逻辑集中在一个模块，修复一次全部生效
  • leverage: 两个消费者共享一个接口
  • 回测和实盘结果一致性得到保证
  • 测试: 一次编写，两种模式验证
