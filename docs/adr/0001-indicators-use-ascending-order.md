# 0001: indicators 模块内部使用升序

`indicators/` 统一技术指标模块内部约定使用升序（oldest first）处理数据，尽管 `base_strategy.py` 和大多数策略文件当前使用降序（newest first）。

**理由**：`pandas` 的 `.rolling()` / `.ewm()` 天然按索引顺序工作，升序是最自然的计算方向。当前 `utils/technical.py` 虽然对外暴露降序接口，但内部也是先反转成升序再算——说明升序才是正确的计算方向。大多数内联实现已经是升序。每个指标函数内部自动检测输入排序并处理转换，调用方无需关心。

**考虑过的替代方案**：内部用降序，对外统一降序。但这会导致所有 pandas 计算都需要反转两次（输入反转 + 输出反转），性能开销不必要。
